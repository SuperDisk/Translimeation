# Translimeation
[English romhack of Slime Mori Mori](https://nickfa.ro/wiki/Slime_MoriMori_Translation_Hack)

This is a work-in-progress romhack of an old Japan-only GBA game.

# AI/LLM disclaimer

This project was started in 2021, and was done completely without the use of LLMs.

In 2023-2024, Gerb and Ockess hand-translated the whole thing from scratch, but I never cut a proper release using this script.

In 2026, I used LLMs to fixup some bugs in the text injector and cut a proper release. No LLMs were used in translation.
